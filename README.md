# TrackThat mobile app

Fitness tracking app, Cross-Platform Application.

## Tech Stack

- Ionic
- Angular
- Capacitor
- GoogleAuth | User Authentication
- @ngx-translate | Internationalization support

## Hosting

Hosted on Vercel.

## Requirements

- Node.js
- npm
- Ionic CLI

- Install Ionic CLI globally:

```
npm install -g @ionic/cli
```

## Development

To serve this app on `http://localhost:8100` :

```bash
ionic serve
```

## Environment Variables

```
GOOGLE_CLIENT_ID=your-google-client-id
```

## Versions

| Technology | Version |
|---|---|
| Ionic | 8.0.0 |
| Angular | 20.0.0 |

Check versions locally:

```
ng version
ionic info
node --version
```
